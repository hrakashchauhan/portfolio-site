# BUILD-PLAN — Akash Kumar portfolio ("Field Notes")

Last updated: June 2026. This is the plan I (the build agent) committed to before writing code, plus the
decisions and assumptions I made along the way. Read `README.md` to run/deploy and `CONTENT-TODO.md` for the
real facts still needed from Akash.

---

## 1. The one job of this site

Turn a stranger — recruiter, founder, operator — into someone who wants to talk to Akash, by proving he is a
capable **operator moving toward project management**, not "another AI student." Bias everything toward
**proof over potential** (~60% evidence / 40% reflection). Dominant verbs: built, led, ran, shipped, decided,
tracked, fixed. Never the word "learning" as an identity.

---

## 2. Stack & tooling — decision

**Hand-authored static HTML + one CSS layer + one small vanilla-JS file.** No framework, no build step.

Why:
- It is a brochure/content site. A SPA framework would be dead weight and hurt the Lighthouse ≥ 95 target.
- "Output must be static, fast, trivially deployable" — this *is* the output. Drag-to-Netlify works with zero build.
- It must be **fully readable with JS disabled** and **work over `file://`** with no tooling. So: a single
  `js/main.js` loaded with `defer` (a classic script, **not** an ES module — modules are blocked by the
  `file://` CORS policy). JS is pure enhancement (scroll-reveal, highlighter sweep, footer year).

### Environment reality (this machine)
`git`, Node/npm, and a real Python are **not installed**; the only `python.exe` is the inert Windows-Store alias.
Chrome and Edge **are** installed. Adaptations:
- **Assets** (OG image + favicons) are authored as HTML/SVG templates and rasterised with **headless Chrome**
  (`scripts/generate-assets.ps1`). This also happens to match the notebook aesthetic perfectly.
- **Fonts** are self-hosted: `scripts/fetch-fonts.ps1` downloads the woff2 files once into `assets/fonts/`.
  If the fetch ever fails (offline), the site degrades to system serif/mono stacks — it still ships and looks intentional.
- **Dev server**: `scripts/serve.ps1` (a tiny PowerShell `HttpListener`) since there is no `python -m http.server`
  / `npx serve`. The site also opens fine by double-clicking `index.html`.
- **Git**: not available to run here. I ship a `.gitignore` and `scripts/git-init.ps1` that recreates the
  intended milestone commits once git is installed, plus the commit sequence is documented in `README.md`.
- **Lighthouse / HTML validator / axe**: no binaries to run. I hand-verify instead — contrast ratios computed
  against the palette (below), markup checked by hand, and headless Chrome used for console-error checks and
  responsive screenshots at 360 / 768 / 1024 / 1440. Reported honestly in the final summary.

## 4. Design system — "Field Notes" (kept and refined, not replaced)

### 4.0 Prior art — `reference.html` is the loved, established version
The workspace already contained `reference.html`: a complete prior build of the notebook site — the established
identity LAYER 3/7 tell me to keep the soul of. **Decision: refine this proven base rather than invent a fresh
design.** I port its visual language verbatim (ruled paper, margin marginalia, taped photo, status tags, numbered
Field Notes, type & color feel) and fix the gaps that fail the brief:
1. **Semantic headings** — the reference has *no* `<h1>/<h2>/<h3>` (sections are styled `<span>`s). I add real
   headings (one `<h1>`, an `<h2>` per section, `<h3>` per work item), visually matching the old `.label` look.
2. **JS-off readability** — the reference's `.rv{opacity:0}` is **not** gated, so with JS disabled every section
   below the hero is invisible. I gate the hidden state behind `<html class="js">` (set by a tiny inline script),
   so no-JS renders everything visible. Same gate for the highlighter's collapsed initial state.
3. **Operator > learning** — rebalance copy to active verbs (built/led/ran/decided/tracked); demote "intern/
   in training/learning" framing without erasing the honest growth arc.
4. **Assets + SEO** — generate the real OG image and favicons; complete `<head>` (og:image→`assets/og-image.png`,
   twitter title/description, og:image:alt, site_name, theme-color, manifest, apple-touch); fix JSON-LD jobTitle
   from "Founder's Office Intern" to an operations/PM framing.
5. **Honest metric slots** — the reference defines `.fill` (dotted-underline) but never uses it; I add the tasteful
   editable slots the placeholder policy requires (flagship metric strip, IIIT accuracy/dataset, VS-Kart counts).
6. **Self-host fonts** (was Google CDN) and **externalise** CSS/JS into organized files (tokens separated).
7. Merge the reference's extra "What I'm looking for" into **Contact** so the page is exactly the LAYER 6 eleven.
The original `reference.html` is kept in the repo as design provenance (not deployed; it is not `index.html`).

A working notebook: warm ruled paper, fountain-pen ink, a left **margin column** of handwritten-style mono
marginalia, a **highlighter** sweep on one key phrase per section, honest **bracketed status tags**, and the
**numbered Field Notes** as the signature. A taped-in photo in the hero margin.

### Tokens (tuned for WCAG AA — I verified contrast and adjusted two)
```
--paper #F7F6F1   --ink #1B1D24   --ink-soft #5E5E66*   --rule #E4E1D6
--pen #2B3A87     --hl rgba(247,212,84,.55)   --red #B23A2E   --green #256B43*
```
`*` tuned from the brief's starting values for AA: `--ink-soft` darkened `#6E6E72 → #5E5E66`
(secondary/marginalia text now ≈ 5.8:1 instead of a borderline 4.6:1); `--green` darkened
`#2E7D4F → #256B43` (status-tag text ≈ 6.0:1). Verified ratios on `--paper`: ink ≈ 15.8:1, ink-soft ≈ 5.8:1,
pen ≈ 9.5:1, red ≈ 5.6:1, green ≈ 6.0:1 — all ≥ 4.5:1. A dark "after-hours" variant is added via
`prefers-color-scheme: dark` (stretch goal) with its own verified ramp.

### Type
Body serif **Newsreader** (400/600 + 400 italic for marginalia/quotes); labels/mono **IBM Plex Mono** (400/500).
Self-hosted, `font-display: swap`, fallbacks `Georgia, 'Times New Roman', serif` and
`ui-monospace, 'Cascadia Code', Consolas, monospace`. One modular scale; tight vertical rhythm on desktop
(small row-gap, larger margin↔body column-gap) — deliberately avoiding the "large empty bands" failure mode.

### Layout
Per section: a CSS grid of `[margin-col] [body-col]`. Margin holds the section number + a mono marginalia note.
A faint vertical pen-rule sits on the margin boundary (real-notebook margin line). On ≤ 768px the margin
column collapses: notes move **above** their section as a small italic aside, and the page becomes single-column.

### Motion (all guarded by `prefers-reduced-motion: reduce`)
- Scroll-reveal via `IntersectionObserver`; initial hidden state applied **only** when `<html class="js">`
  (set by a tiny inline script), so JS-off renders everything visible.
- Highlighter sweep: a `<mark>` background grows 0→100% width when its section reveals. Reduced-motion shows it
  fully painted with no animation.

## 6. Non-negotiables I'm holding to
- **Zero fabricated facts.** No invented numbers, duties, projects, or quotes. Missing numbers → tasteful
  dotted-underline mono **slots** + adjacent HTML comments + a line in `CONTENT-TODO.md`. The only testimonial
  is Major Deepak Raj's; a commented template waits for real ones (incl. Sudhanshu Shukla's exact words).
- **A11y is a requirement**: semantic landmarks, logical headings, skip link, `:focus-visible`, AA contrast,
  real alt text, `lang="en"`, reduced-motion, readable with JS off.
- **SEO/sharing**: unique title/description/canonical, OG + Twitter wired to the generated OG image, JSON-LD
  `Person`, robots/sitemap/manifest, favicons (svg + png + apple-touch).
- **Performance**: deferred JS, sized images, limited font weights; target Lighthouse ≥ 95 (hand-verified here).
- **No analytics, cookies, or third-party trackers.** Self-hosted fonts keep it to first-party only.

## 8. Redesign — "The Operating Ledger" (June 2026 — supersedes the notebook)
Akash reviewed the first build (the Field Notes notebook) and rejected it, supplying 16 candidate design
directions. Decision was made via a 4-lens evaluation workflow (recruiter / founder / senior designer /
positioning strategist) scoring all 16. Consensus: a **Swiss Grid (04) chassis + Operating Board (09) status
taxonomy + Ledger (02) shipped/killed/live language + a persistent CTA (14) + generous whitespace (06)**, with the
honest voice kept as copy. The synthesis = **The Operating Ledger**:
- **Type:** Inter (400/600/800) + IBM Plex Mono (500), self-hosted. No serif.
- **Colour:** off-white `#FBFBFA`, ink `#16181D`, one electric-blue accent `#1B4DFF`, status tints
  (live green `#0B7A4B` / shipped blue / killed rust `#B23A1E`). AA/AAA verified; status = label + glyph + colour.
- **Signature device:** a flat, typographic **status ledger** (NOT a draggable kanban) — the form is the proof.
  Jeevan Jhola sits in a `KILLED` row, framed as judgment ("the most useful thing I've decided so far was to stop").
- **Sections:** header(CTA) · hero · the ledger · what I bring · how I got here · field notes · principles ·
  what I'm sharpening · testimonial · contact(verified closing line). All real content; zero fabricated numbers.
- The notebook CSS/HTML were fully rewritten; the old serif/paper/highlighter aesthetic is retired. No dark theme
  in v1 (one disciplined light system). `reference.html` (and the original notebook) kept only as provenance.
